## Mô tả
Ứng dụng Client-Server cho phép hiển thị danh sách file trên Server và tải nhiều file đồng thời bằng giao diện GUI.

## Chức năng dự kiến
- Hiển thị danh sách file trên Server
- Chọn nhiều file để tải
- Tải đồng thời nhiều file
- Hiển thị tiến trình từng file
- Xử lý lỗi tải file
- Xử lý file trùng tên
